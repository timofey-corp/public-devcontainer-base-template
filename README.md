# README.md
> WARNING: This is an experimental repo. Which may break at any time.

This is a Devcontainer setup, based on 
[timofey-corp/public-devcontainer-base-image](https://github.com/timofey-corp/public-devcontainer-base-image).
This includes tools like: node, claude code, codex, beads, htmlq, pandoc 
and other addons like Playwright MCP.

This base template is designed to be extended via ./devcontainer
